# Alien-Invasion
Alien Invasion game created with Python / Pygame (First Beginner Project)

Alien Invasion

Overview
--------
Alien Invasion is a 2D arcade shooter built in Python using Pygame.
The project demonstrates object-oriented design, event-driven programming,
collision detection, sprite management, and game-state control.

Features
--------
• Player movement
• Enemy fleet generation
• Projectile mechanics
• Collision detection
• Play button and game state
• Lives system
• Dynamic fleet movement

Technologies
------------
Python 3
Pygame

Skills Demonstrated
-------------------
• Object-oriented programming
• Modular software architecture
• Debugging
• Game loops
• Event handling
• Collision detection
